## ADDED Requirements

### Requirement: 會員限定的報告列表
系統 SHALL 提供「研究報告」頁面，僅限已登入且通過會員資格判斷的使用者檢視報告列表（標題、日期、摘要）。

#### Scenario: 已登入會員查看報告列表
- **WHEN** 已登入且通過會員資格判斷的使用者開啟「研究報告」頁面
- **THEN** 系統回傳並顯示目前所有報告的標題、日期、摘要

#### Scenario: 未登入使用者嘗試查看報告列表
- **WHEN** 未登入的使用者開啟「研究報告」頁面或直接呼叫報告列表 API
- **THEN** 系統拒絕回傳報告資料，並導向登入或回應未授權錯誤

### Requirement: 報告內容不外洩雲端硬碟真實位置
系統 SHALL 確保使用者的瀏覽器在任何情況下（頁面原始碼、網路請求）都無法取得報告檔案所在雲端硬碟的分享連結、簽名網址或其他可脫離本站直接存取檔案的網址。所有報告檔案內容的傳輸皆須經由本站後端向雲端硬碟服務取得後再轉發給瀏覽器。

#### Scenario: 檢視報告時網路請求只指向本站網域
- **WHEN** 已登入會員在報告列表點擊某篇報告的標題連結
- **THEN** 瀏覽器發出的請求網址皆為本站網域路徑，不包含雲端硬碟服務的網域或任何雲端硬碟核發的存取憑證

#### Scenario: 報告列表 API 不回傳雲端硬碟檔案識別資訊
- **WHEN** 系統回傳報告列表資料
- **THEN** 回傳內容僅包含標題、日期、摘要與本站內部報告代號，不包含雲端硬碟的檔案 ID、分享連結或任何可用於直接存取雲端硬碟的資訊

### Requirement: 點擊標題直接檢視報告，不需額外登入 Google
系統 SHALL 讓已登入且通過會員資格判斷的使用者，點擊報告列表中的標題連結後，直接看到報告內容（PDF 或圖片），不需要先進入中間頁面，也不需要使用者另外對 Google 或雲端硬碟服務進行任何登入或授權——會員資格的判斷只依據本站自己的登入 session。

#### Scenario: 會員點擊標題直接檢視報告
- **WHEN** 已登入會員在報告列表點擊某篇報告的標題
- **THEN** 系統經由後端向雲端硬碟取得該報告內容，依實際檔案類型（PDF 或圖片）以可直接檢視的形式呈現給使用者，且過程中不出現任何 Google 帳號登入或存取授權的畫面

### Requirement: 未登入或非會員無法存取報告內容
系統 SHALL 在報告檢視的伺服器端入口驗證登入狀態與會員資格，不可僅依賴前端頁面的存取限制。

#### Scenario: 未登入使用者直接呼叫報告檢視端點
- **WHEN** 未攜帶有效登入 session 的請求直接呼叫報告檢視的 API 端點
- **THEN** 系統拒絕存取並回應未授權錯誤，不回傳任何報告內容
