# Proposal: HomePage 補上績效分析入口

## Why

過去 4 個 changes 完成了 `/performance` 績效分析頁的完整功能（資料層 / 個股矩陣 / 圖表 / 跨頁連結 / 診斷引擎 / 報告匯出），NavBar 也已新增「績效分析」導覽項目。但 HomePage 還停留在舊版，存在以下缺口：

1. **3 張工具卡片只涵蓋前向分析**（個股 / 組合 / 比較），沒有後向分析（績效）的入口
2. **頁面副標只提到「期望值、風險值與市場行為指數」**，未反映新功能（勝率、賠率、獲利因子等）
3. **計算邏輯說明只列 EV / VaR / Hurst 三項**，缺少績效分析特有的指標（賠率、獲利因子）
4. **使用說明流程僅描述前向流程**（選股 → API 載入 → 顯示結果），未涵蓋後向流程（上傳交易紀錄 → 診斷 → 匯出）

第一次造訪首頁的使用者看不到績效分析功能存在，必須從 NavBar 才能發現——這降低了功能曝光度。

## What Changes

### 1. 工具卡片重新組織為兩組（前向 vs 後向）

```
[H2] 進場前評估
  ┌──────────┬──────────┬──────────┐
  │ 個股分析  │ 投資組合  │ 比較分析  │
  └──────────┴──────────┴──────────┘

[H2] 出場後反思
  ┌──────────────────────────────┐
  │ 績效分析（NEW）              │
  │ 上傳交易紀錄分析勝率、賠率、   │
  │ 獲利因子；自動診斷 + PDF 匯出 │
  └──────────────────────────────┘
```

### 2. Hero 副標更新

舊：「選取股票，即時計算期望值、風險值與市場行為指數」
新：「**進場前**用市場資料評估標的；**出場後**用交易紀錄反思績效——一站式投資分析工具」

### 3. 計算邏輯說明擴充為 4 項

加入「賠率與獲利因子」一欄，呈現後向分析特有指標。

### 4. 使用說明流程合併前後向

新增第 5 條：「**或**前往「績效分析」上傳已完成的交易紀錄，看勝率 / 賠率 / 4 象限診斷」

### 5. 範圍

- **本 change**：HomePage 視覺改造、文案更新、第 4 張卡片
- **不在範圍**：不動 NavBar / 各分析頁、不增新計算 / API、不改主題色

## Capabilities

### Modified Capabilities
- `result-first-layout`：HomePage（首頁）的工具卡片由 3 張擴為 4 張（含績效分析入口），並重新組織為「前向 / 後向」兩個群組

## Impact

- `src/pages/HomePage.tsx`：4 張卡片組織為兩個視覺群組（含 H2 標題）；Hero 副標更新；計算說明 grid 改 4 欄；使用說明加第 5 條
- 無 API、store、其他元件異動

預期工作量：30–45 分鐘
