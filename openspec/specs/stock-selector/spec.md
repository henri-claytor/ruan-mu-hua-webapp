## ADDED Requirements

### Requirement: 股票搜尋選擇器元件

系統 SHALL 提供 `StockSelector` 元件，允許使用者輸入股票代號或名稱關鍵字，從下拉清單選取股票，選取後觸發 API 數據抓取。

#### Scenario: 輸入代號搜尋

- **WHEN** 使用者在搜尋框輸入 `"2330"`
- **THEN** 下拉清單顯示符合的股票（如 `2330 台積電`），最多 10 筆

#### Scenario: 輸入名稱搜尋

- **WHEN** 使用者輸入 `"台積"`
- **THEN** 下拉清單顯示所有名稱含「台積」的股票

#### Scenario: 選取股票後觸發抓取

- **WHEN** 使用者從下拉清單點選 `2330 台積電`
- **THEN** 元件顯示已選取股票名稱，並觸發月報酬 + 日報酬 API 並行呼叫

#### Scenario: 清單載入中顯示狀態

- **WHEN** 股票清單尚未載入完成
- **THEN** 搜尋框顯示「載入股票清單中...」並禁用輸入

#### Scenario: 無符合結果

- **WHEN** 使用者輸入的關鍵字無任何符合的股票
- **THEN** 下拉清單顯示「找不到符合的股票」

### Requirement: 選取後顯示數據載入狀態

`StockSelector` 選取股票後，父元件 SHALL 顯示載入中指示器直到 API 數據返回。

#### Scenario: 數據載入中

- **WHEN** 使用者選取股票且 API 尚未回應
- **THEN** 結果區顯示 Skeleton 載入態，搜尋框標示「載入中...」

#### Scenario: 數據載入完成

- **WHEN** 月報酬與日報酬 API 均回應完成
- **THEN** Skeleton 消失，結果區顯示完整分析結果

#### Scenario: 重新選取股票

- **WHEN** 使用者在已有結果的情況下選取另一支股票
- **THEN** 舊結果清空，顯示新股票的載入態，載入完成後顯示新結果
