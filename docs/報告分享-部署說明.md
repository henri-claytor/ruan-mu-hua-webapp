# 報告分享功能 — 合併與部署說明

> 給專案維護者（作者 / Vercel 專案擁有者）：本 PR 新增「報告分享」會員功能。
> 合併後**還需要在 Vercel 設定環境變數**才能正常運作，否則報告功能會報錯。

---

## 這個 PR 做了什麼

- 新增「報告分享」頁：列出指定 Google 雲端硬碟資料夾內的報告，點擊在網站內嵌檢視器開啟（PDF / 圖片）。
- 後端以 **service account 代理**讀取雲端硬碟檔案 —— 瀏覽器全程只接觸自家網域路徑，**不會拿到雲端硬碟的網址**。
- 內嵌檢視器隱藏下載 / 列印 / 存檔按鈕（非防拷措施，僅移除明顯入口；截圖無法防止）。
- 不影響現有四個分析工具（個股 / 投資組合 / 比較 / 績效）。

---

## 作者要做的事（依序）

### 步驟 1｜審閱並合併 PR
- 建議先看 Vercel 自動產生的 **Preview 部署**（PR 頁面會有連結）確認畫面。
- 注意：Preview 環境一樣要有下列環境變數才看得到報告內容。

### 步驟 2｜在 Vercel 專案設定環境變數
到 Vercel 專案 → Settings → Environment Variables，新增下列變數（Production 與 Preview 都要）。
變數清單與說明見下方表格；**實際值由 Gary 另行（安全管道）提供**，勿貼在公開處。

### 步驟 3｜確認 Google 端設定
- **雲端硬碟資料夾**：需分享給 service account 的 email（唯讀）。放報告的資料夾就是報告來源。
- **報告檔名命名規則**：`日期-標題.副檔名`，日期為 `YYYYMMDD` 或 `YYYY-MM-DD`。
  例：`20260721-立隆電.pdf` → 顯示日期 2026-07-21、標題「立隆電」。
  之後新增 / 下架報告只要在資料夾內增減檔案即可，**免改程式、免重新部署**。

### 步驟 4｜部署後驗證
1. 開網站 →「報告分享」，確認報告列表出現。
2. 點一則報告，確認 PDF / 圖片能在內嵌檢視器顯示。
3. 確認網路請求都指向自家網域、沒有出現 `drive.google.com` 網址。

## 環境變數清單

| 變數 | 用途 | 值來源 | 機密 |
|------|------|--------|------|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | 後端讀雲端硬碟的服務帳號金鑰（整包 JSON 壓成一行） | Gary 安全提供，或作者自建 service account 並把資料夾分享給它 | **高機密** |
| `GOOGLE_DRIVE_FOLDER_ID` | 報告資料夾 ID | Gary 提供 | 否 |
| `SESSION_JWT_SECRET` | 簽發登入 session 的密鑰 | 任意足夠長的隨機字串（作者自訂即可，與本機不需相同） | 是 |
| `GOOGLE_OAUTH_CLIENT_ID` | （過渡期）Google 登入用；統登接上後移除 | Gary 提供 | 否（前端本就會帶出） |
| `AUTH_BYPASS` | 開發過渡：略過登入直接放行 | **正式站不要設**（見下方安全提醒） | — |

變數名稱也可對照專案根目錄的 [`.env.example`](../.env.example)。

---

## ⚠️ 安全提醒：登入機制目前是過渡狀態

這批報告是**取得的第三方研究報告（有版權考量）**，存取控制很重要：

- **絕對不要在正式站設 `AUTH_BYPASS=true`** —— 那會關掉所有登入檢查，讓任何人都能看報告（等於公開散布）。`AUTH_BYPASS` 只用於本機開發。
- 正式站在**未接公司統登（CMoney OIDC）之前**，若要對外開放：
  - 預設會回退為 **Google 登入**當作臨時關卡（需登入才看得到報告）。但 Google OAuth 同意畫面目前仍在「測試」模式，只有加入測試使用者的帳號能登入；要對一般會員開放需另行處理（或直接等統登）。
  - **建議**：等公司統登（CMoney OIDC）接上、以統登作為會員關卡後再正式對外開放，較符合「只有有權限的會員能看」的目標。

## 後續待辦（本 PR 未含）

- **接 CMoney 統登（OIDC）**取代 Google 登入：只需替換登入檢查點（後端 `api/_lib/session.ts` 的 `requireMember`、前端 `src/store/useAuthStore.ts`），報告與讀檔邏輯不用動。
- 若要根治 PDF 內建的佔位標題（部分報告 metadata 有「(XXXX) XXXX」），可請報告來源修正檔案，或在後端加一段清除 PDF metadata 標題。
